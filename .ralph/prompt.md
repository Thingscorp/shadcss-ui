# Ralph Per-Iteration Contract

You are a fresh agent in a Ralph loop iteration. You have no memory of prior iterations. All context you need is in the files under `.ralph/` and the repo itself.

## Hard rules

1. **Do exactly ONE item** — the one assigned to you. Do not touch other items.
2. **Run the gate**: When you believe the work is done, run `bash scripts/check.sh`. Only flip `passes: true` in `.ralph/items.json` if the output ends with `ALL GATES PASS` (exit 0).
3. **Commit the change**: Use a conventional-commit message (e.g. `fix(fidelity): button paddingY to 8px`). **NO AI / "Claude" / "generated by" attribution** in the commit message or code.
4. **Append progress**: Add one entry to `.ralph/progress.md` with a timestamp, what you did, and the gate result.
5. **Stay on the branch**: Work only on `ralph/fidelity-gaps`. **Never** push, merge, force-push, or touch the `main` branch.
6. **Never commit secrets**: No API keys, tokens, or credentials in any file.
7. **Read the plan**: Check `.ralph/plan.md` for invariants you must not break.
8. **Read regression notes**: Each item has `regression_notes` — re-check those specific things.

## Workflow

1. Read the item's `description`, `steps`, and `regression_notes`.
2. Read the relevant source files in the repo.
3. Make the minimal change needed to close the gap.
4. Run `npm run build` to rebuild dist.
5. Run `bash scripts/check.sh`.
6. If ALL GATES PASS: flip `passes: true` in `.ralph/items.json`, commit, append to `.ralph/progress.md`.
7. If gates fail: fix the issue and re-run. Do not flip `passes: true` until green.
