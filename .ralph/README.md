# Ralph Loop

Ralph is a self-verifying autonomous work loop. Each iteration is a **fresh agent with no memory** of prior iterations. All durable knowledge lives in files under `.ralph/`.

## How it works

1. **Read state**: The engine reads `.ralph/loop.md`, `.ralph/items.json`, `.ralph/plan.md`, `.ralph/prompt.md`, and `.ralph/progress.md`.
2. **Pick one item**: The FIRST item where `passes: false` and `blocked: false` is selected.
3. **Do the work**: A fresh agent is spawned with the item + per-iteration contract. It does exactly ONE item.
4. **Verify**: The agent runs `bash scripts/check.sh`. The item flips to `passes: true` **only** if the gate output ends with `ALL GATES PASS` (exit 0).
5. **Commit & log**: On green, the change is committed (conventional-commit, no AI attribution) and one entry is appended to `.ralph/progress.md`.
6. **Advance**: The iteration counter in `.ralph/loop.md` is incremented. Live context is thrown away.

## Durable state files

| File | Purpose |
|------|---------|
| `.ralph/plan.md` | The objective + non-negotiable invariants |
| `.ralph/items.json` | Work items + runtime contract |
| `.ralph/prompt.md` | Per-iteration contract handed to each fresh agent |
| `.ralph/loop.md` | Live loop state (running, iteration, stop_reason) |
| `.ralph/progress.md` | Append-only progress log |

## Skills

| Skill | Description |
|-------|-------------|
| `/ralph-plan <goal>` | Generate or refresh the plan + items for a goal |
| `/ralph-loop [N]` | Run N iterations of the engine (default: 1) |
| `/ralph-status` | Print current state |
| `/ralph-stop` | Halt the loop |

## Invariants

- Exactly **ONE item** per iteration.
- Gate must be **green** (`ALL GATES PASS`) before any item flips to `passes: true`.
- **No secrets** committed to git.
- **No AI / "Claude" / "generated by"** attribution in commits or code.
- Work **only** on a dedicated `ralph/<topic>` branch — **never** the default branch.
- **Never push or merge** without explicit owner approval.
