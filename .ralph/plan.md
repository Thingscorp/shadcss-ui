# Ralph Plan — shadcss-ui fidelity gaps

## Objective

Close the remaining shadcn fidelity gaps identified in `qa/fidelity/gaps.csv`:
- button paddingY (shadcn: 8px, shadcss: 0px)
- input paddingY (shadcn: 4px, shadcss: 0px)
- toggle paddingX (shadcn: 8px, shadcss: 0px)
- progress background (shadcn: primary, shadcss: mix:primary)

Each gap must be fixed in the source CSS, the build must succeed, and all
consistency + markup checks must pass.

## Non-negotiable invariants

1. **Public API stability**: The package exports (`dist/shadcss.min.css`, `dist/shadcss.css`, `src/shadcss.css`) must remain valid and buildable.
2. **Component count**: The number of component CSS files must match `registry.json` entries and doc badges (enforced by `check-consistency.mjs`).
3. **Version consistency**: `package.json`, `packages/shadcss/package.json`, and `packages/shadcss/registry.json` versions must stay in sync.
4. **No absolutist claims**: Never reintroduce "0 JavaScript" or "zero JavaScript" claims.
5. **Registry conformance**: `registry.json` must not claim the shadcn `$schema`.
6. **Closed-overlay guard**: `reset.css` must retain `dialog:not([open]) { display: none }` and `[popover]:not(:popover-open) { display: none }`.
7. **No anchor() without anchor-name**: Component CSS must not use `anchor()` without a corresponding `anchor-name` producer.
8. **No popover on navigation-menu-content**: The `popover` attribute must not appear on `.navigation-menu-content`.
9. **No static aria-selected on tabs**: CSS cannot sync `aria-selected`; do not add it to tab triggers.
10. **No invalid CSS properties**: e.g. `focus-visible-anchor` must never appear.
11. **No AI attribution**: Commits and code must not contain "Claude", "AI", or "generated by" attribution.
12. **Branch-only**: Work only on `ralph/fidelity-gaps` — never touch `main` directly.
