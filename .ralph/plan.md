# Ralph Plan — shadcss-ui comprehensive shadcn fidelity

## Objective

Achieve and maintain **zero real deviations** against the official shadcn/ui
specification (`qa/fidelity/shadcn-spec.json`) while keeping every component
lightweight (pure CSS, no JS framework dependency).

This means:
1. Fix all 4 currently-known real deviations (button paddingY, input paddingY, toggle paddingX, progress background).
2. Audit every component category against shadcn for missing slots, styles, or variants.
3. Improve the fidelity comparator to reduce false "not comparable" results (currently 99 slots).
4. Ensure all shadcn/ui components have a CSS-only equivalent with matching visual fidelity.
5. Make the fidelity comparator a hard gate once real deviations reach 0.

## Component categories to audit

- **Notifications**: sonner (toast), toast, alert
- **Menus**: dropdown, menubar, context-menu, navigation-menu
- **Overlays**: dialog, alert-dialog, sheet, drawer, popover, hover-card, tooltip
- **Forms**: input, textarea, select, checkbox, radio, radio-group, switch, slider, toggle, toggle-group, label, field, input-otp
- **Data display**: table, card, avatar, badge, skeleton, progress, separator, accordion, tabs, collapsible
- **Navigation**: breadcrumb, pagination, sidebar
- **Layout**: container, aspect-ratio, resizable, scroll-area, carousel
- **Feedback**: progress, spinner, empty
- **Typography**: typography, kbd
- **Utility**: calendar, command

## Non-negotiable invariants

1. **Public API stability**: The package exports (`dist/shadcss.min.css`, `dist/shadcss.css`, `src/shadcss.css`) must remain valid and buildable.
2. **Component count**: The number of component CSS files must match `registry.json` entries and doc badges (enforced by `check-consistency.mjs`).
3. **Version consistency**: `package.json`, `packages/shadcss/package.json`, and `packages/shadcss/registry.json` versions must stay in sync.
4. **No absolutist claims**: Never reintroduce "0 JavaScript" or "zero JavaScript" claims.
5. **Registry conformance**: `registry.json` must not claim the shadcn `$schema`.
6. **Closed-overlay guard**: `reset.css` must retain `dialog:not([open]) { display: none }` and `[popover]:not(:popover-open) { display: none }`.
7. **No anchor() without anchor-name**: Component CSS must not use `anchor()` without a corresponding `anchor-name` producer.
8. **No popover on navigation-menu-content**: The `popover` attribute must not appear on `.navigation-menu-content`.
9. **No static aria-selected on tabs**: CSS cannot sync `aria-selected`; do not add it to tab triggers.
10. **No invalid CSS properties**: e.g. `focus-visible-anchor` must never appear.
11. **Lightweight**: Every component must remain CSS-only (no JS framework dependency). Consumer JS is acceptable for interactive features (e.g. `showModal()`, `showPopover()`).
12. **No AI attribution**: Commits and code must not contain "Claude", "AI", or "generated by" attribution.
13. **Branch-only**: Work only on `ralph/fidelity-gaps` — never touch `main` directly.
